# Milestone report: Plan v3 lean run (2026-11-21)

Full analysis: `runs/bench-v3/milestone.md`, generated by `tools/milestone_report.py`. Task list, arms and gates were
pre-registered in `demo/tasks_milestone.yaml` and [improvement-plan.md](improvement-plan.md) before any run.

## Setup

- **Tasks:** 134 frozen multistep tasks (93 bench v3 docs-site tasks plus 41 bench v2 multistep or vague tasks), on 51
  sites. They are replayed offline from widened HAR snapshots ([bench-v3.md](bench-v3.md)).
- **Agents:** Claude Haiku 5.5, Claude Sonnet 5.5, GPT-6 Luna and GPT-6.1 Terra. Each runs every task once per arm,
  with arm order shuffled per task.
- **Totals:** 1,608 runs, with 0 timeouts, 0 agent errors and 0 live requests. Archive misses average 3.45 per run.
- **Arms:**
  - baseline = `a11y-cap` (20k-character capped accessibility snapshot);
  - **B** = `find+observe@exact` (keyword-ranked goal digest);
  - **C** = `find+observe@exact+blend:dist/xs-s0:8` (model-ranked digest).

  Text passages are keyword-ranked in both B and C.
- **Analysis:** pooled over agents and paired by (task, agent), with a site-cluster bootstrap (4,000 draws).

tokens or latency.

The success CI for B also clears the secondary −5-point bound (−5.9 does not).

## What this does and does not show

- It shows that a goal-aware compact view keeps pooled success within the margin while cutting tool output about 7×
  and Claude cost about 3×.
- It does **not** show an advantage over existing tools. The baseline is a capped full snapshot, which is weaker than
  Playwright MCP's depth-limited snapshots with `browser_find`, or agent-browser's `snapshot -i -c`. The next step is
  the competitor comparison ([competitors.md](competitors.md), Plan v4 in [improvement-plan.md](improvement-plan.md)).
  The token reduction is not a competitive claim until that comparison exists.
- All v3 sites are developer documentation, where keyword matching is strong. The model's offline advantage (next-step
  recall on Mind2Web, user-written descriptions) did not carry over to these agent tasks.
