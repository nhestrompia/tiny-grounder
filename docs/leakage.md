## Overlap per evaluation source

Kinds: **domain** = registrable domain (eTLD+1, as `grounder.data.crawl.registrable_domain`; Mind2Web site names are matched by name, or by second-level label against web domains); **URL** = normalised exact URL (no scheme/`www.`/fragment/trailing slash, sorted query); **app** = app name (bundle-id tail / `gnome-` prefix tolerant, >=4 chars); **near-dup** = Jaccard >= 0.9 of the normalised element-text sets (MinHash LSH + exact check; only pages with >= 5 distinct texts are comparable); **cross** = near-dup whose training page is on a different domain/app.

## Caveats

- Screen2AX pages are anonymised (hashed app ids, no app names), so app overlap cannot be measured for them; only content near-duplicates can catch them.
- Mind2Web page URLs are `mind2web://{site}`; domain overlap there means the same **site**, which is by design for test_task and test_website only if the site was also in train.
- Content matching ignores pages with fewer than 5 distinct element texts (tiny app windows share generic labels such as Close/Minimize).
- The agent-task block only has URLs, not page content, so only domain and URL overlap apply to it.
